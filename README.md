# ReviewBuddy ⭐

**Happy customers don't refuse to review. They just forget.**
ReviewBuddy asks every customer at the right moment and turns their own words (tapped, filled in, or spoken in English, Hindi, Marathi or Hinglish) into a Google review in under a minute.

## Features
| | |
|---|---|
| 🎤 **Voice in 3 languages** | Browser speech-to-text (en-IN, hi-IN, mr-IN). Hinglish is understood. |
| ✨ **Honest AI drafting** | Gemini writes only from what the customer said. Negative points stay in. Short/Detailed and "Another version" options. Falls back to a no-AI draft if the key is missing or the call fails. |
| ✍️ **Fill-in-the-blank** | Rotating sentence templates with the shop's own menu or services. |
| 💬 **WhatsApp requests** | Staff send the review link to customers who leave without scanning. |
| 🔁 **Smart follow-up** | One gentle reminder ~20h later, only once, with a "Reviewed" mark. Phone numbers are hidden after 7 days. |
| 📈 **Live Google count** | Optional: auto-fetches review count and rating every 30 min via Places API. |
| 🧠 **AI owner insights** | What customers love, issues, and 3 actions for this week. |
| 📊 **Dashboard** | 7-day chart, funnel, mood split, languages, one-click report for the write-up, CSV export. |
| 🏪 **Multi-business** | Add a shop from the dashboard (brand colour, emoji, menu). No code edits or redeploy. |
| 🖨 **QR poster** | A5 printable, branded. QR is generated by the app itself. |
| 🛡 **Safety** | Rate-limited AI endpoint, staff PIN, admin key, HTML escaping, preview mode never counts. |

**Built on Google's review rules:** everyone gets the same flow and is sent to Google, happy or unhappy (no review gating). No rewards. Customers post from their own account.

## Pages
`/` home · `/r/<shop>` customer · `/staff/<shop>` staff (PIN) · `/poster/<shop>` QR poster · `/dashboard` owner (admin key) · `/health`

## Run on Mac
```bash
cd review-buddy
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
export ADMIN_KEY=admin123
export GEMINI_API_KEY=your_key          # optional, free key at https://aistudio.google.com/apikey
export GOOGLE_PLACES_KEY=your_key       # optional, auto review count
uvicorn main:app --reload --host 0.0.0.0
```
Open http://127.0.0.1:8000. To test on your phone over the same WiFi, use `http://<your-Mac-IP>:8000` (find the IP with `ipconfig getifaddr en0`).

## Adding a shop
Easiest: **Dashboard → ＋ Add business**. Or edit `shops.json`:
`slug, name, type (restaurant | clinic | salon | shop), menu[], review_url, staff_pin, baseline_reviews, color, emoji, place_id (optional)`

## Deploy (Render, free)
Push to GitHub → Render → New → Blueprint → set env vars `ADMIN_KEY`, `GEMINI_API_KEY` (+ optional `GOOGLE_PLACES_KEY`).
Render's free disk resets on restart, so use Supabase for storage: create a project, run the SQL below, and set `SUPABASE_URL` + `SUPABASE_KEY` (service_role key).
```sql
create table events (id bigint generated always as identity primary key, slug text, type text, value double precision, ts double precision);
create table drafts (id bigint generated always as identity primary key, slug text, text text, overall text, lang text, ai int, ts double precision);
create table asks   (id bigint generated always as identity primary key, slug text, name text, phone text, ts double precision, reminded_ts double precision, done int default 0);
create table shops  (slug text primary key, data text, ts double precision);
```
